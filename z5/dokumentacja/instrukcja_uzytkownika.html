Instrukcja Użytkownika

System Ewidencji Pracowników w architekturze MVC | Egzamin Zawodowy INF.04

1. Opis Programu

Aplikacja służy do rejestracji, przeglądania oraz usuwania rekordów pracowników w przedsiębiorstwie. Została wykonana w technologii Java Swing z pełnym rozdzieleniem logiki na warstwy: Model (baza danych), View (interfejs graficzny) oraz Controller (obsługa zdarzeń i walidacja).

2. Wymagania i Uruchomienie

  • Zainstalowane środowisko Java (JRE lub JDK 11+).
  • Uruchomienie z pliku JAR:
java -jar ProjektEgzaminacyjny-wykonywalny.jar
  • Uruchomienie przez Maven:
mvn compile exec:java -Dexec.mainClass="com.egzamin.Main"

3. Obsługa Formularza i Przyciski

  1. Dodawanie pracownika: Wypełnij pola Imię, Nazwisko, wybierz Stanowisko oraz podaj kwotę w polu Wynagrodzenie. Następnie naciśnij przycisk Dodaj pracownika. W przypadku błędnych danych aplikacja wyświetli stosowny komunikat.
  2. Usuwanie pracownika: Kliknij na żądany wiersz w tabeli, a następnie naciśnij przycisk Usuń zaznaczonego. W wyświetlonym oknie dialogowym potwierdź decyzję.
  3. Wyczyść formularz: Resetuje wszystkie pola tekstowe i anuluje zaznaczenie w tabeli.
  4. Odśwież listę: Ponownie odczytuje wszystkie dane z bazy danych.

4. Reguły Walidacji Danych

Pole Reguła walidacji Przykładowa poprawna wartość
Imię Wymagane, minimum 2 litery, wyłącznie litery i myślnik. Jan, Anna-Maria
Nazwisko Wymagane, minimum 2 litery, wyłącznie litery i myślnik. Kowalski, Nowak-Zielińska
Stanowisko Wybór z listy rozwijanej (JComboBox). Programista, Tester oprogramowania
Wynagrodzenie Liczba rzeczywista większa od 0 (obsługuje kropkę i przecinek). 6500, 7250.50
